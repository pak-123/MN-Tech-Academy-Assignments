What is !DOCTYPE html?

It tells the browser that this is an HTML5 document.


What is html lang="en"?

HTML is the root of the document. Everything goes inside it. lang="en" defines the language as English.


What is head tag in HTML?

This tag contains meta information. It is not visible on the page, but it is important. It is used for links, title, icons, and CDN.


What is meta charset="UTF-8"?

It tells the browser to display text correctly on the webpage.


What is meta viewport?

It makes the website responsive and fit properly on all devices.


What is title tag?

It sets the name of the webpage that appears on the browser tab.


What is body tag?

The body tag contains everything you see on the webpage like images, text, buttons, and headings.


What is HTML?

HTML stands for HyperText Markup Language. HyperText means text that can link to other pages. Markup means using tags to define elements. It is not a programming language, it is a markup language. HTML is the skeleton of a webpage and creates the structure of a website.
